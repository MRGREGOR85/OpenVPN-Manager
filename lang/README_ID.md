## 💀 Apa itu GHOST-NET?

Pengelola VPN di jendela CMD biasa. Ia menghubungkan Anda lewat OpenVPN ke server penyedia VPN Anda sendiri, sehingga situs web melihat IP server, bukan IP Anda. Ia memakai file server yang sama dengan [GhostVPN](https://github.com/MRGREGOR85/GhostVPN-BETA). Program ini tersedia dalam 29 bahasa. Tekan `TAB` di layar utama untuk mengganti bahasa.

## ✨ Fitur

| Fitur | Fungsinya |
|---|---|
| **19 penyedia VPN** | NordVPN, ProtonVPN, Surfshark, Mullvad, dan lainnya. Ganti dengan tombol panah atau angka. |
| **Ping langsung** | Daftar server menunjukkan server mana yang paling cepat. |
| **Kill switch** | Windows Firewall memblokir internet di luar VPN. Jika terowongan putus, IP Anda tidak bocor. Jaringan rumah tetap berfungsi. |
| **Perlindungan DNS** | Kueri DNS tidak keluar dari terowongan. |
| **Layar koneksi** | IP baru, kota, penyedia, ping, dan enkripsi. |
| **Speedtest** | Tes kecepatan dengan file 1 GB, hasil dalam Mbit/s. |
| **Galat cerdas** | Laporan di Notepad, saran server berikutnya, dan unduhan otomatis server NordVPN baru. |
| **29 bahasa** | Program ini tersedia dalam 29 bahasa. Tekan `TAB` di layar utama untuk mengganti bahasa. |

## 📖 Panduan

<br>

### 1️⃣ Unduh

Klik **Unduh GHOST-NET**. Pindahkan **GhostNet.exe** ke folder tersendiri, misalnya `C:\GHOST-NET`, karena skrip menyimpan pengaturan dan login di sebelahnya.

<br>

### 2️⃣ Jalankan

Klik dua kali **GhostNet.exe** dan klik **Ya** saat Windows meminta izin. Jika Windows menampilkan peringatan: **Info selengkapnya** → **Tetap jalankan**. Saat pertama kali dijalankan, pilih bahasa Anda.

<img src="../screenshots/language-select.png" alt="29 bahasa" width="100%">

📸 **29 bahasa.** Program ini tersedia dalam 29 bahasa. Tekan `TAB` di layar utama untuk mengganti bahasa.

<br>

### 3️⃣ Pilih negara

Ketik kode negara dan tekan **Enter**, misalnya `pl`, `de`, atau `us`. Ganti penyedia dengan tombol panah atau angka dari `1` sampai `19`.

<br>

### 4️⃣ Pilih server

Ketik nama server dari daftar, atau awalnya saja, misalnya `pl1273`, lalu tekan **Enter**.

<img src="../screenshots/server-ping.png" alt="Daftar server dengan ping" width="100%">

📸 **Daftar server.** Setiap server menampilkan ping dalam kurung, yaitu waktu respons: makin sedikit `ms`, makin cepat. `udp` biasanya lebih cepat, `tcp` lebih mudah menembus blokir. Di bawah Anda mengetik server pilihan.

<br>

### 5️⃣ Masukkan login (hanya pertama kali)

Skrip meminta nama pengguna dan kata sandi OpenVPN dan memberi tahu di mana menemukannya. NordVPN dan Surfshark memakai *Service credentials* terpisah, bukan email dan kata sandi akun.

<img src="../screenshots/login.png" alt="Login pertama" width="100%">

📸 **Login pertama.** Skrip menunjukkan login ini untuk penyedia mana dan di mana mendapatkannya. Kata sandi disembunyikan dengan tanda bintang. Login disimpan sekali, jadi tidak perlu diketik lagi.

<br>

### 6️⃣ Selesai

<img src="../screenshots/connected.png" alt="Layar koneksi" width="100%">

📸 **Terhubung.** `NODE_IP` adalah IP baru Anda yang dilihat situs web. `PING` adalah kecepatan terowongan, `ENCRYPTION` enkripsinya, dan `KILL_SWITCH` menunjukkan apakah internet di luar VPN diblokir. `LOCATION` dan `PROVIDER` adalah kota dan perusahaan server. Di bawah: `1` speedtest, `2` putuskan, `3` kill switch.

## ⌨️ Perintah

| Ketik | Fungsinya |
|---|---|
| `pl`, `de`, `us`… | server di negara itu |
| `1` … `19` | ganti penyedia VPN |
| `TAB` | ganti bahasa |
| `ks` | kill switch nyala atau mati |
| `fs` | layar penuh atau jendela |
| `Alt+C` | putuskan VPN (berfungsi di mana saja) |
| `1` / `2` / `3` saat terhubung | speedtest / putuskan / kill switch |

## 🆘 Ada yang tidak berfungsi?

| Yang saya lihat | Yang harus dilakukan |
|---|---|
| **OpenVPN**: belum terpasang | Pasang [GhostVPN](https://github.com/MRGREGOR85/GhostVPN-BETA) atau [OpenVPN](https://openvpn.net/community-downloads/). |
| **.ovpn**: tidak ada file server | Tambahkan server penyedia ini di GhostVPN, atau pilih penyedia lain. |
| **AUTH_FAILED** | Pilih `1` untuk mencoba server berikutnya. Jika tidak ada yang berhasil, pilih `2` dan masukkan login lagi. |
| **TUNNEL FAILED** | Baca laporan di Notepad. Pilih server lain. |
| Tidak ada internet setelah jendela ditutup | Jalankan skrip dan pilih **LEPAS BLOKIR**, atau ketik `ks`. |

> 🔒 Login hanya tersimpan di komputer Anda, di folder di sebelah skrip. Jangan berikan folder itu kepada siapa pun.
