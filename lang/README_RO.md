## 💀 Ce este GHOST-NET?

Un manager VPN într-o fereastră CMD obișnuită. Te conectează prin OpenVPN la un server al propriului furnizor VPN, astfel încât site-urile văd IP-ul serverului în loc de al tău. Folosește aceleași fișiere de servere ca [GhostVPN](https://github.com/MRGREGOR85/GhostVPN-BETA). Programul vorbește 29 de limbi. Apasă `TAB` pe ecranul principal ca să schimbi limba.

## ✨ Funcții

| Funcție | Ce face |
|---|---|
| **19 furnizori VPN** | NordVPN, ProtonVPN, Surfshark, Mullvad și alții. Schimbi cu săgețile sau cu un număr. |
| **Ping în timp real** | Lista de servere arată care server este cel mai rapid. |
| **Kill switch** | Firewall-ul Windows blochează internetul în afara VPN. Dacă tunelul cade, IP-ul tău nu se scurge. Rețeaua de acasă continuă să funcționeze. |
| **Protecție DNS** | Interogările DNS nu ies din tunel. |
| **Ecranul conexiunii** | IP nou, oraș, furnizor, ping și criptare. |
| **Test de viteză** | Test de viteză cu un fișier de 1 GB, rezultat în Mbit/s. |
| **Erori inteligente** | Raport în Notepad, propunerea următorului server și descărcarea automată a serverelor NordVPN noi. |
| **29 de limbi** | Programul vorbește 29 de limbi. Apasă `TAB` pe ecranul principal ca să schimbi limba. |

## 📖 Ghid

<br>

### 1️⃣ Descarcă

Apasă **Descarcă GHOST-NET**. Mută **GhostNet.exe** într-un folder propriu, de exemplu `C:\GHOST-NET`, pentru că scriptul salvează setările și datele de autentificare lângă el.

<br>

### 2️⃣ Pornește

Dă dublu clic pe **GhostNet.exe** și apasă **Da** când Windows cere permisiunea. Dacă Windows afișează un avertisment: **Mai multe informații** → **Rulează oricum**. La prima pornire, alege-ți limba.

<img src="../screenshots/language-select.png" alt="29 de limbi" width="100%">

📸 **29 de limbi.** Programul vorbește 29 de limbi. Apasă `TAB` pe ecranul principal ca să schimbi limba.

<br>

### 3️⃣ Alege țara

Scrie un cod de țară și apasă **Enter**, de exemplu `pl`, `de` sau `us`. Schimbi furnizorul cu săgețile sau cu un număr de la `1` la `19`.

<br>

### 4️⃣ Alege serverul

Scrie numele serverului din listă sau doar începutul lui, de exemplu `pl1273`, și apasă **Enter**.

<img src="../screenshots/server-ping.png" alt="Lista de servere cu ping" width="100%">

📸 **Lista de servere.** Fiecare server arată ping-ul între paranteze, adică timpul de răspuns: cu cât mai puține `ms`, cu atât mai rapid. `udp` este de obicei mai rapid, `tcp` trece mai ușor de blocări. Jos scrii serverul ales.

<br>

### 5️⃣ Introdu datele de autentificare (doar prima dată)

Scriptul îți cere numele de utilizator și parola OpenVPN și îți spune unde le găsești. NordVPN și Surfshark folosesc *Service credentials* separate, nu e-mailul și parola contului.

<img src="../screenshots/login.png" alt="Prima autentificare" width="100%">

📸 **Prima autentificare.** Scriptul arată pentru ce furnizor sunt datele și de unde le iei. Parola este ascunsă cu asteriscuri. Datele se salvează o singură dată, data viitoare nu mai trebuie scrise.

<br>

### 6️⃣ Gata

<img src="../screenshots/connected.png" alt="Ecranul conexiunii" width="100%">

📸 **Conectat.** `NODE_IP` este noul tău IP pe care îl văd site-urile. `PING` este viteza tunelului, `ENCRYPTION` criptarea, iar `KILL_SWITCH` arată dacă internetul în afara VPN este blocat. `LOCATION` și `PROVIDER` sunt orașul și compania serverului. Jos: `1` test de viteză, `2` deconectare, `3` kill switch.

<br>

## ⌨️ Comenzi

| Scrie | Ce face |
|---|---|
| `pl`, `de`, `us`… | servere din acea țară |
| `1` … `19` | schimbă furnizorul VPN |
| `TAB` | schimbă limba |
| `ks` | kill switch pornit sau oprit |
| `fs` | ecran complet sau fereastră |
| `Alt+C` | deconectează VPN (merge oriunde) |
| `1` / `2` / `3` când ești conectat | test de viteză / deconectare / kill switch |

## 🆘 Ceva nu merge?

| Ce văd | Ce fac |
|---|---|
| **OpenVPN**: neinstalat | Instalează [GhostVPN](https://github.com/MRGREGOR85/GhostVPN-BETA) sau [OpenVPN](https://openvpn.net/community-downloads/). |
| **.ovpn**: fără fișiere de server | Adaugă serverele acestui furnizor în GhostVPN sau alege alt furnizor. |
| **AUTH_FAILED** | Alege `1` ca să încerci următorul server. Dacă niciunul nu merge, alege `2` și introdu din nou datele. |
| **TUNNEL FAILED** | Citește raportul din Notepad. Alege alt server. |
| Fără internet după închiderea ferestrei | Pornește scriptul și alege **ELIMINĂ BLOCAREA** sau scrie `ks`. |

> 🔒 Datele de autentificare rămân doar pe calculatorul tău, în folderul de lângă script. Nu da nimănui acest folder.
