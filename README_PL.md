## 💀 Czym jest GHOST-NET?

Menedżer VPN w zwykłym oknie CMD. Łączy Cię przez OpenVPN z serwerem Twojego dostawcy VPN, a strony widzą IP serwera zamiast Twojego. Korzysta z tych samych plików serwerów co [GhostVPN](https://github.com/MRGREGOR85/GhostVPN-BETA). Program mówi w 29 językach. Język zmienisz klawiszem `TAB` na ekranie głównym.

<br>

## ✨ Funkcje

| Funkcja | Co robi |
|---|---|
| **19 dostawców VPN** | NordVPN, ProtonVPN, Surfshark, Mullvad i inni. Przełączasz strzałkami albo numerem. |
| **Ping na żywo** | Przy liście serwerów widzisz, który jest najszybszy. |
| **Kill switch** | Zapora Windows blokuje internet poza VPN. Gdy tunel padnie, Twoje IP nie wycieknie. Sieć domowa dalej działa. |
| **Ochrona DNS** | Zapytania DNS nie wychodzą poza tunel. |
| **Ekran połączenia** | Nowe IP, miasto, dostawca, ping i szyfr. |
| **Speedtest** | Test prędkości na pliku 1 GB, wynik w Mbit/s. |
| **Mądre błędy** | Raport w Notatniku, propozycja następnego serwera, a dla NordVPN samo pobranie nowych serwerów. |
| **29 języków** | Program mówi w 29 językach. Język zmienisz klawiszem `TAB` na ekranie głównym. |

## 📖 Instrukcja

<br>

### 1️⃣ Pobierz

Kliknij **Pobierz GHOST-NET**. Przenieś **GhostNet.exe** do własnego folderu, na przykład `C:\GHOST-NET`, bo program zapisuje obok siebie ustawienia i loginy.

<br>

### 2️⃣ Uruchom

Kliknij **GhostNet.exe** dwa razy i kliknij **Tak**, gdy Windows zapyta o uprawnienia. Jeśli pojawi się ostrzeżenie Windows: **Więcej informacji** → **Uruchom mimo to**. Przy pierwszym starcie wybierz swój język.

<img src="screenshots/language-select.png" alt="29 języków" width="100%">

📸 **29 języków.** Program mówi w 29 językach. Język zmienisz klawiszem `TAB` na ekranie głównym.

<br>

### 3️⃣ Wybierz kraj

Wpisz kod kraju i naciśnij **Enter**, na przykład `pl`, `de` albo `us`. Dostawcę zmieniasz strzałkami albo numerem od `1` do `19`.

<br>

### 4️⃣ Wybierz serwer

Wpisz nazwę serwera z listy albo jej początek, na przykład `pl1273`, i naciśnij **Enter**.

<img src="screenshots/server-ping.png" alt="Lista serwerów z pingiem" width="100%">

📸 **Lista serwerów.** Każdy serwer ma w nawiasie ping, czyli czas odpowiedzi: im mniej `ms`, tym szybciej. `udp` jest zwykle szybsze, `tcp` lepiej przechodzi przez blokady. Na dole wpisujesz wybrany serwer.

<br>

### 5️⃣ Podaj login (tylko za pierwszym razem)

Program zapyta o login i hasło do OpenVPN i podpowie, gdzie je znaleźć. U NordVPN i Surfshark to osobne *Service credentials*, a nie e-mail i hasło do konta.

<img src="screenshots/login.png" alt="Pierwsze logowanie" width="100%">

📸 **Pierwsze logowanie.** Program pokazuje, dla którego dostawcy podajesz dane i skąd je wziąć. Hasło jest ukryte gwiazdkami. Login zapisuje się raz i przy następnych połączeniach nie trzeba go wpisywać.

<br>

### 6️⃣ Gotowe

<img src="screenshots/connected.png" alt="Ekran połączenia" width="100%">

📸 **Połączono.** `NODE_IP` to Twoje nowe IP, które widzą strony. `PING` to szybkość tunelu, `ENCRYPTION` to szyfr, a `KILL_SWITCH` mówi, czy internet jest zablokowany poza VPN. `LOCATION` i `PROVIDER` to miasto i firma serwera. Na dole: `1` speedtest, `2` rozłącz, `3` kill switch.

## ⌨️ Komendy

| Wpisz | Co robi |
|---|---|
| `pl`, `de`, `us`… | serwery w tym kraju |
| `1` … `19` | zmiana dostawcy VPN |
| `TAB` | zmiana języka |
| `ks` | kill switch: włącz albo wyłącz |
| `fs` | pełny ekran albo okno |
| `Alt+C` | rozłącz VPN (działa wszędzie) |
| `1` / `2` / `3` po połączeniu | speedtest / rozłącz / kill switch |

## 🆘 Coś nie działa?

| Co widzę | Co zrobić |
|---|---|
| *„OpenVPN nie zainstalowany”* | Zainstaluj [GhostVPN](https://github.com/MRGREGOR85/GhostVPN-BETA) albo [OpenVPN](https://openvpn.net/community-downloads/). |
| *„Nie znaleziono plikow .ovpn”* | Dodaj serwery tego dostawcy w GhostVPN albo wybierz innego dostawcę. |
| **AUTH_FAILED** | Wybierz `1`, żeby spróbować następnego serwera. Jeśli żaden nie działa, wybierz `2` i wpisz login jeszcze raz. |
| **TUNNEL FAILED** | Przeczytaj raport w Notatniku. Wybierz inny serwer. |
| Brak internetu po zamknięciu okna | Uruchom program i wybierz **WYLACZ BLOKADE** albo wpisz `ks`. |

> 🔒 Loginy zostają tylko na Twoim komputerze, w folderze obok programu. Nie dawaj nikomu tego folderu.
